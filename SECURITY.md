# Security policy

Security fixes target the current default branch. This repository contains research
software; reproducibility results do not establish suitability for clinical or
regulatory deployment.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/edithatogo/tobac/security/advisories/new).
Include the affected revision, reproducible steps and a minimal synthetic example.
Keep credentials, private source documents, personal data and operational evidence
out of public issues and pull requests. Do not send live credentials or sensitive
data in a vulnerability report.

The maintainer will assess reports and coordinate fixes and disclosure. No response
time or support commitment is implied. Dependency alerts, code scanning, secret
scanning, checksum-pinned tools and reproducible tests are complementary controls;
a passing check is not a guarantee that the software has no vulnerabilities.
