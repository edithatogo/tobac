The connector verified immutable release v2.2.0, target 7af563c8cb373057d30662650b3f332f39e05b83. The Linux wheel listed by the release has SHA256 `8eb3ba00ec24efcc2f8213141a0343456f28a4cfa8ae25ca9d5d19ad4effe119`. The released `voiage/methods/basic.py` accepts a NumPy value array for EVPI; blob `e4bf0b486f3e5760fdfed4e939bf0b69a9134192` was inspected.

The weighted-contrast adapter and exact structure/group averaging pass independent finite fixtures. The ACTUAL installed-package probe failed with PackageNotFoundError. Container DNS and browser downloads did not provide the wheel. The repository therefore records external qualification as BLOCKED, not a mocked pass. A separate hosted job downloads the declared asset, verifies its hash, installs it and executes the probe. Its dependency resolution is not claimed to be the reference environment's transitive lock. Existing reference/canary/lock gates remain unchanged.

Do not call the upstream structural aggregation as a structure-only estimator without testing that estimand. `tobac` resolves model identity by averaging nuisance states before maximisation. No Voiage source was patched and no independent scientific validation of the library is asserted.

## Innovate
Conditional uptake profiles change the sign of reference-study ENBS. That establishes sensitivity to uptake, not the fitness of a diffusion model. Keep Innovate optional until actual adoption data and a qualified fit improve on the transparent profiles. A simulated curve with added noise is not automatically a posterior draw; an unadjusted mean difference is not automatically a causal policy effect. Transfer only labelled trajectories with their estimand, uncertainty and provenance.

## Kairos
Prompt versus slower reporting changes the research decision in the two-stage reference. An operational queue/delay adapter is worth considering if measured collection, laboratory capacity, batching or decision deadlines explain those delays. Do not add a DES or ABM solely to make the project more elaborate. Kairos was not installed or executed. Its future output must parameterise timing/cost distributions, not redefine the VOI estimand or double-count effects already in the payoff horizon.

## Reproducibility boundaries
The executed stack is Python 3.13.5, NumPy 2.3.5, SciPy 1.17.0. No mandatory scientific dependency changed. Nox configuration is additive; Nox and the online full-checkout tooling were not executed locally. Sourceright and CiteWeft remain separately unexecuted. A declared asset hash or source review is not an installation receipt. The local test scope and source hashes are in `integration/m3_local_verification.json`.
