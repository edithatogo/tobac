# Executable integration of preserved evidence

Connect restored historical material to shared verification without silently promoting it to
current observations or scientific priors. Extend the existing qualification wrapper and reuse
prior-work checks, Sourceright, Nox and context profiles. Preserve both model namespaces and M3.
All required collections must be covered; additional collections must not be silently omitted.
Failures, missing tools and nonfinite external results must never produce qualification.
