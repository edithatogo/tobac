# M2 public-data-only direction — 27 October 2026

The owner superseded the request-preparation direction: “No requests. Only use
existing public data rather than requesting new data.” No request had been sent.

Use existing public reports, publications, supplements, public data repositories,
agency datasets, Cabinet/briefing releases and already-published OIA responses.
Do not contact authors/custodians, submit access applications, file a new OIA,
commission analyses or collect data. The reference to OIA is treated as a question
about sources, not authority to submit a request. Reuse of a published OIA release
is public-source review; a new OIA would be a new request and is outside scope.

The four prepared letters are withdrawn, retained solely as versioned historical
work. Their field schedule can identify what public sources contain or omit; it
must not drive outreach. Public-only gaps remain explicit; no request is the
presumed next step. Retain conditional bounds/no-study findings where public
records do not identify a quantity. Earlier empirical/custodian gates describe
limits, not an active access plan.

All other selected boundaries remain: hypothetical-cap conditional research,
separate societal/budget consequences, no paid commitments, no normative-weight
selection and public aggregate output. No model inputs or observations changed.
