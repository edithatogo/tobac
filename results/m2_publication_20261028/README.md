# Conditional publication analysis — 28 October 2026

Primary run: four cessation nodes; grid-2/ and grid-8/ are numerical challenges.
[Report](report.json), [manifest](manifest.json),
[methods and findings](../../docs/research/M2_CONDITIONAL_PUBLICATION.md),
[dated protocol](../../docs/research/M2_PUBLICATION_PROTOCOL.md).

- consequences.csv: expected synthetic action consequences. Native daily exposure
  rates, normalised health/crime/resource scores and fiscal volume are distinct units.
  mean_state_illicit_share is an average of state-specific ratios, not a national share
  or necessarily the ratio of expected illicit and total volumes.
- decisions.csv: all co-optimal actions at each declared case/value profile.
- grouped_evppi.csv: perfect information about finite, overlapping parameter partitions;
  not additive values or continuous-parameter inference.
- study_value.csv: gross EVSI and same-objective cost ceilings before actual study costs.
- scientific_information.csv: target-specific expected information in nats; independent
  of value weights for a fixed prior/target/report channel.
- thresholds.csv: isolated upper-envelope crime-weight ties at fixed resource weights.
- robustness.csv: co-optimality throughout the continuous declared weight rectangle.
  An empty co-optimal cell is an empty set, not a missing observation.
- source_use.csv: context/applicability links; no new target-observation adoption.
- PNG/SVG figures: declared grid and one labelled study-value slice. Lines in the slice
  are display guides between evaluated points, not an analytical EVSI frontier.

No probabilities over normative profiles or structural cases; no empirical NZ posterior,
QALYs, NZD budget, community preference estimate, ethics approval or submission.
The original captured documents remain local; metadata does not prove their possession
in a fresh checkout. See integration/m2_publication_20261028/ for official-guidance
and inherited-model original-byte/WARC verification records.

README is explanatory packaging added after numerical execution and is not an output
listed in the computational manifest. The publication package manifest binds it separately.
