# Methods-source and reporting tables

This extends the preserved empirical map with methodological/reporting references.
It creates no new target observation, likelihood or preference estimate.

- source_index.csv: 11 source/document IDs and actual access/object metadata, with undated web guidance distinguished from publication years.
- source_table.csv:methodological roles, exact locators, funding/design/access appraisal and no-adoption flags.
- claim_table.csv: 10 critical methodological claims linked to sources/locators.
- references.csl.json:corresponding citation identities; four DOI metadata responses separately verified.
- search_log.csv: 20 executed query strings; English terms, no date restriction, combined-batch/ranking and retained-result limits.
- candidate_dispositions.csv: 32 unique literal URLs from the two fully retained result batches, not all results of all 20 queries.
- citation_edges.csv:three selected native reference edges; not a complete citation graph.
- reporting_crosswalk.csv:all 34 topic IDs displayed in CHEERS-VOI Table 2, plus base 28 correspondence and truthful status/reasons.
